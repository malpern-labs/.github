### Projects

| | |
|---|---|
| **[KeyPath](https://github.com/malpern-labs/KeyPath)** | Keyboard remapping for macOS, built on Kanata. Tap-hold keys, layers and launchers, set up without a config file. [Docs](https://malpern.github.io/KeyPath/) |

More projects will move here over time. The rest are on [@malpern](https://github.com/malpern?tab=repositories).

### How we work

Most code here is written with AI coding agents and checked by CI before anything merges. Pull requests go through a merge queue, and nothing reaches `master` without passing its required checks. To report a security problem, use the project's **Security** tab rather than a public issue.
